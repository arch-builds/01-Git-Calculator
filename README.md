# Git Calculator

A beginner calculator project for practicing Git and GitHub workflow.

## Files
- `calculator.py` - command-line calculator
- `operations.py` - Python math functions
- `index.html` - web calculator interface
- `style.css` - web calculator styling
- `script.js` - web calculator logic
- `.gitignore` - Git ignore rules

## Current Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus

## Assignment Goal
Create a feature branch and add a **Clear** button to the web calculator, then practice the full Git/GitHub workflow:
branch → code → test → commit → push → pull request → merge → pull → delete branch.
